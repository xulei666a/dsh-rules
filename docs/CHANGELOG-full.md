## 0.57.0 (2026-10-31)

**修复助手对话往上翻时被刷新滚回底部。**

- 根因：2.5s 轮询每次都整块重绘消息并 `scrollTop = scrollHeight`。
- 修法：给消息列表算指纹，内容没变就不重绘；重绘时记录「原本是否在底部」「原滚动位置」——在底部才跟随到底，正在往上翻则保持原位置。
- 「新会话」重置时清空指纹与渲染标记。
- 纯 UI 改动，刷新面板即生效，无需重启。

## 0.43.0 (2026-10-31)

**适用面筛选：5 个维度 + 三个维度各带 是/否，判定按补集算。**

- 下拉：全部 / 默认生效 / 当前对话生效 / 非默认当前对话生效 / 待复核。
- 选中后三个维度（默认生效 / 当前对话生效 / 非默认当前对话生效）时，右侧出现 是/否 下拉（是=生效，否=不生效/补集）。
- 判定规则：
  - 默认生效：是 = 默认规则；否 = 非默认（局部规则）。
  - 当前对话生效：是 = 默认规则 + 本对话已打开的局部规则；否 = 本对话不生效的局部规则。
  - 非默认当前对话生效：是 = 本对话已打开的非默认规则；否 = 其它（默认 + 本对话未打开的局部）。
- 是/否的 title 提示随维度切换，说明"是/否"各代表什么。
- 校验：check-ui70 8 项；selftest 110 项不变。
- **纯 UI 改动**，刷新面板即可。

## 0.41.0 (2026-10-31)

**生效方式改成「是 / 否」两个选择，覆盖"不生效"的两种状态。**

- 详情里「适用面」下拉换成两个是/否选择：**默认生效（是/否）** + **当前对话生效（是/否）**。
  - 默认=是 → 当前对话自动=是且锁定（每个对话都生效）。

- 当前级永远显示为一列胖卡片（默认是全部大类）；点开一个分类后，它缩成一条**带颜色高亮的路径行**（同款 ▶ 三角样式，1 级 1 行往下加），同级其它项缩成一排小三角、可点击切换。
- 下一级是子分类 → 显示子分类胖卡片（说明行「N 个子类 · 点击展开」）；下一级是具体准则 → 直接在该级显示准则胖卡片（说明行「点击查看该类准则」），**规则树与分类树合并为一个流**。
- 点彩色路径行 = 收起返回上一级；点小三角 = 切换到同级；点「未分类」= 查看未归类准则。
- 去掉分类区所有虚线框（原「移到顶级」拖拽区、未分类虚线）；分类卡悬停操作为 ＋/✎/⤒（移到顶级）/✕；规则卡悬停可「移出」分类。
- 搜索/状态筛选直接作用于显示的准则；输入关键词时显示匹配结果，点搜索路径行清空返回。拖拽仍是移动语义（节点/规则落到分类卡、路径行或小三角上）。

## 0.4.3 (2026-10-29)

- 修正分类树的默认展示：**默认状态下所有同级分类都是"胖卡片"**（与准则条同构）；点击其中一个后，该分类保持胖卡片并展开子级，**同级其它分类才收成小三角**。之前把默认/展开态搞反了（默认全缩成三角）。
- 收起逻辑逐级：点开卡片=展开并让同级收缩；再点它=收起一层，上一级重新全部展开为胖卡片。

## 0.4.2 (2026-10-29)

- 分类卡片右侧标签显示「分类」+「自身/含子类 条数」，下方说明行显示子类数量 / 描述 / 点击提示；展开收起、悬浮 ＋/✎/✕、拖拽移动保留。
- 折叠的大类仍显示为 `▶ 标题 计数` 小三角行。

## 0.4.1 (2026-10-29)

- 分类 UI 改为**单列圆角卡片流**（去掉左树右表）：分类与具体规则在同一个竖列里，卡片样式统一；点开一个大类后其它大类缩成小三角，层级只靠展开/收起表达、**不再按深度缩进**（任意层级视觉一致）。
- 分类卡片显示 `自身/含子类` 计数；展开后子级卡片与父级同款外观，只多一个 `↳` 深度标记。
- 交互：点卡片=展开/收起，点小三角=展开该大类；规则区在下方同列，随所选分类变化；「显示全部 / 未分类」在同一列。
- 拖拽沿用移动语义（节点/规则），落点改为分类卡片、小三角或顶部「移到顶级」区。

## 0.4.0 (2026-10-29)

**破坏性变更**：平铺分组升级为**多套分类方案 + 任意层级分类树**（`groups.json` v2，旧数据自动迁移成一个「个人分组」方案）。

- 数据层 `lib/tree.js`：schemes → 树节点；规则归属唯一（placements 显式移动 + 选择器自动归类，DFS 首命中），**只移动不复制**。
- 节点操作：任意层级增删改、移动（不能移进自己的子孙）、移到顶级；删除节点连同子类。
- UI：左侧竖向手风琴分类树——点大类展开子类、其它大类收起；节点悬浮 `＋/✎/✕`；拖拽节点或规则移动，拖到顶部=顶级、拖到「未分类」=移到未分类；方案下拉 + 新建/改名/删除/恢复默认。
- 内置默认方案：产出交付 / 记忆与底线 / 工作方式 / 工具与环境 4 大类 + 15 个小类，自动归类。
- API/CLI/工具：`/dsh-rules/tree`（GET/POST）、CLI `groups list|show|scheme|node|move`、`rules_groups` 新 op；`/list` 返回当前方案的 `nodeId`。
- 自检扩到 25 项（分类树方案/节点/移动唯一性/防环）。
